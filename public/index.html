archivedownloader is a port of The Ultimate Uzi Archive (uziarchive.top), the Lil Uzi Vert archive run by @flexbymistake. The idea, the layout and the features all come from that site. This is just the same thing remade to work with the Yeat tracker. Go use the original.

  • Original site and design: uziarchive.top by @flexbymistake
  • Song data: the Yeat Trackër, edited by raglord, red., shock, Snarke and zamfir
  • Files: hosted on pillows.su and imgur.gg

Everyone who made the original and edits the tracker is on the Credits page. This port isn't made or run by @flexbymistake, so please don't send them problems with it.

This site doesn't host or store any music. It only lists what the tracker lists and links out to it. All music, artwork and trademarks belong to their owners.
